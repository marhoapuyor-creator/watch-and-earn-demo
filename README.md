# Watch & Earn — Demo scaffold

What this is
- A minimal website demo for a media/gaming platform.
- Includes a homepage, video page, game page, ad placeholders, and a simple server.
- Intended as a starting point for a monetized content site.

Quick start
1. In the project folder, run:
   npm install
2. Start the app:
   npm start
3. Open in browser:
   http://localhost:3000

Pages
- Home: http://localhost:3000/
- Video demo: http://localhost:3000/video/sample
- Game demo: http://localhost:3000/game/sample-game

Notes
- Replace ad placeholders with approved ad network code after registering with an ad partner.
- Never incentivize users to click ads or fake engagement.
- For production, add a privacy policy, analytics, and anti-fraud view filters.

Next steps for a real site
- Add real video hosting and CDN delivery.
- Add user auth and admin management.
- Connect a real database such as PostgreSQL.
- Integrate ad network SDKs or banner code.
- Deploy to Render, Vercel, or a VPS with Nginx.
